# CASTÚO-SYSTEM: An Offline-First Approach

**CASTÚO-SYSTEM** is an open, modular technology ecosystem that integrates cloud computing, edge infrastructure, artificial intelligence, IoT, workflow automation and observability into a unified digital platform. Its interoperable components can operate independently or together, enabling scalable solutions for agriculture, environmental monitoring, industrial systems and smart territories.

Our focus on **Offline-First** capabilities ensures resilience and operational continuity in environments with limited or no connectivity. This is achieved through a layered architecture:

1.  **Knowledge Layer (Kiwix):** Offline library for reference and educational content.
2.  **Assistance Layer (Local AI / RAG):** Local AI for documentation queries, procedures, and internal guides.
3.  **Visual Field Layer (Organic Maps):** Offline mapping for navigation, terrain reference, and field team support.
4.  **Communication Layer (Meshtastic):** Off-grid LoRa mesh for short messages, position, and basic coordination.

These layers are transversally integrated with the **Evidence Center**, where all evidence, releases, protocols, results, and traceability are meticulously recorded.
