## 4. Assurance Evidence & Fail-Closed Gate

**12/12 adversarial tests passing**

The assurance gate is deliberately **fail-closed**: claims are blocked when evidence is missing, stale, inconsistent, benchmarks are below target, or provenance cannot be verified.

### Example: The System Rejects an Unsupported Claim
- Benchmark target: `85.0%`
- Observed result: `82.4%`

```text
82.4% < 85.0%
       ↓
ASSURANCE GATE
       ↓
CLAIM BLOCKED
```

CASTÚO-SYSTEM™ does not upgrade the result to the target and does not permit publication of the unsupported claim.
