# Commercial pilot dossier template

This folder is a **template**, not evidence of a completed commercial pilot. Copy it to a new dossier only after a signed scope exists, and replace every `PENDING` field with dated, reviewed evidence.

## Required sequence

```text
Signed scope → baseline → consent/data boundary → pilot execution
→ raw results → KPI snapshot → security review → invoice/cobro if applicable
→ remediation/re-test → Gate decision → public redacted summary
```

## Commercial boundary

An interview, contact, collaborator, unpaid demonstration or LOI is not counted as a customer, invoice, cobro or recurring revenue unless the corresponding documentary evidence exists and is within the declared scope.

## Data and security boundary

Customer identity, personal data, private telemetry, credentials and commercial terms remain restricted unless explicit permission authorises publication. Local or simulated blockchain transaction IDs must be labelled accordingly and are not public-chain confirmations.

## Promotion rule

The dossier may remain `DOCUMENTED`, `IMPLEMENTED`, `TESTED`, `VALIDATED`, `PILOT` or `OPERATIONAL` only when the Evidence Center validator and the required evidence envelope support that state. Empty fields are pending, not green.
