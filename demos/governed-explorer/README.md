# Explorador del dato gobernado · vista local

**SINTÉTICO · EDUCATIVO · SIN DATOS EN VIVO · SIN ACCIONES OPERATIVAS**

1. Abre [`index.html`](index.html) en GitHub y utiliza **Download raw file** para descargarlo. También puedes descargar el repositorio.
2. Abre el archivo descargado en un navegador moderno. Es autocontenido: no requiere instalación, servidor ni conexión.
3. Selecciona una fuente en los botones o en el dibujo. Recorre sus controles y exporta el caso como JSON si quieres inspeccionarlo.

El HTML conserva el cerebro de referencia y el flujo animado del pie del README. La selección resalta la fuente y actualiza los controles y su ficha. Puedes pausar el movimiento; la preferencia de movimiento reducido del sistema también se respeta. Los botones admiten teclado. En móvil, usa los controles externos al dibujo para leer el detalle.

## Qué muestran los seis casos

| Caso | Resultado ilustrativo |
|---|---|
| Sensor de suelo | Pendiente de valoración humana |
| Dron / satélite | Abstención: procedencia |
| Cuaderno de campo | Abstención: identidad |
| ERP · trazabilidad | Abstención: integridad |
| Motor de reglas | Abstención: permisos |
| Parcela · agua | Abstención: calidad |

Los indicadores son valores declarados en fixtures. No son comprobaciones reales ni hashes verificados. Tras el primer bloqueo, los controles siguientes figuran como no evaluados. La exportación contiene únicamente el caso sintético y su resultado calculado, sin firmas ni acreditación de veracidad.

El explorador no ejecuta los umbrales de grounding ni la cola temporal del SVG. No sustituye a e3bundle, no es la consola de CASTÚO-SYSTEM y no cambia el estado de madurez del proyecto. No utiliza almacenamiento, analítica ni llamadas de red. Los enlaces externos solo se visitan si los abres.
