# PIE PLUS 2026 · CASTÚO-SYSTEM™ — expediente V5.6.2

Este directorio reúne el expediente público de defensa de CASTÚO-SYSTEM™ para PIE PLUS 2026. Incluye la memoria empresarial V5.6.2, el **Excel financiero oficial recalculado**, la presentación resumen para la defensa oral, el dossier de preguntas financieras y el índice de evidencia externa.

## Alcance de la publicación

La memoria distingue entre capacidad tecnológica documentada, evidencia externa, hipótesis comerciales, escenario proforma condicionado y situación financiera real. La publicación no presenta como hechos los clientes, la recurrencia, la financiación desembolsada, los convenios de suelo, los pilotos remunerados o las certificaciones que requieran documentación adicional.

Las fuentes externas tienen funciones diferentes: CTAEX/FOODLAB se utiliza como evidencia de transferencia y contexto de validación técnica; la Junta de Extremadura y Extremadura Empresarial como difusión y reconocimiento institucional; GitHub como evidencia pública de ingeniería; y South Summit únicamente como exposición cuando exista referencia específica verificable.
