# CASTÚO-SYSTEM Transfer Matrix

## Purpose

This matrix records the public information transfer from the CASTÚO control plane into the `Traky12` profile. It is designed to prevent both under-documentation and over-claiming. The profile exposes navigation and bounded summaries; the control plane remains the canonical source for governance, evidence and promotion decisions.

## Non-transferable material

Secrets, credentials, private infrastructure details, personal data, unreviewed operational telemetry, sensitive execution artifacts and unsupported commercial or legal claims must not be copied into the public profile. They remain governed by classification and access controls in the control plane.

## Current projection

> **GREEN-STAGING-CANDIDATE · EVIDENCE-SCOPED · PROMOTION BLOCKED**

This matrix is documentation of public information architecture. It is not a certification, an operational attestation or a promotion decision.
