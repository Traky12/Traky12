# CASTÚO-SYSTEM Information Index

## Purpose

This page is the public navigation layer for the CASTÚO-SYSTEM ecosystem. It connects the `Traky12` profile to the canonical control plane, implementation repositories, evidence records and bounded operating plans. The profile is an entry point; [`castuo-evolution`](https://github.com/Traky12/castuo-evolution) remains the canonical governance and evidence source.

> Repository activity is not operational truth. Identity, capability, implementation, evidence, review and promotion remain separate dimensions.

## Transfer boundary

The profile may publish navigation, bounded summaries, public contracts, repository roles, status references and links to inspectable evidence. It must not copy secrets, sensitive operational artifacts, unreviewed personal data, private infrastructure details or claims that are not supported by the control plane.

The profile must also avoid presenting the UE pilot as legal compliance. The jurisdiction-aware layer is an experimental governance and consistency mechanism. Its policy registry, materialised profile, policy decision, execution evidence and promotion decision remain separate artifacts.

## Current state

> **GREEN-STAGING-CANDIDATE · EVIDENCE-SCOPED · PROMOTION BLOCKED**

This state is a controlled projection of the current evidence boundary. It does not claim production operation, certification, customer deployment, revenue, continuous operation, federation or legal compliance.
