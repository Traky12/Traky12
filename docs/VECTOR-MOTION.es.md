# CASTÚO-SYSTEM — Guía de movimiento vectorial

## Propósito

El proyecto usa el movimiento como ayuda de lectura: recorre un flujo documentado, señala nodos conectados y dirige la atención a un resultado revisable. El movimiento es decorativo e ilustrativo. Nunca representa telemetría en directo, actividad de campo, una aprobación, un estado de producción ni una decisión.

## Reproducción y vista estática

- Los SVG son vectores autocontenidos; no requieren scripts, fuentes externas, hojas de estilo remotas ni dependencias en tiempo de ejecución.
- El visor de imágenes de README de GitHub muestra la obra estática. Abre el SVG directamente en un navegador compatible para ver la animación CSS opcional.
- Cada animación conserva una vista visual estable. El diagrama debe comunicar el flujo completo aunque la animación no esté disponible o esté desactivada.
- `prefers-reduced-motion: reduce` desactiva el movimiento continuo. Las partículas y los trazos animados son solo señales visuales; no son mediciones.
- Los logotipos fuente y sus derivados aprobados quedan fuera de la animación y no se modifican.

## Revisión de cambios

Al cambiar el movimiento, revisa el SVG como imagen fija y en un navegador con animación activa. Comprueba la legibilidad al tamaño del README, el contraste, el ajuste del texto y la preferencia de movimiento reducido. Mantén alineadas la estructura y la temporización de los diagramas en inglés y español. Actualiza esta guía si se añade o elimina un recurso visual o cambia su señal.
