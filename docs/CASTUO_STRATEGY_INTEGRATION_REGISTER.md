# CASTÚO-SYSTEM Strategy Integration Register

## Purpose

This register is the public index for the strategies processed across the CASTÚO-SYSTEM ecosystem. It does not replace the canonical control plane, the frozen V1.0 repository standard or the evidence packages. Instead, it provides a traceable route from the public profile to the authoritative repository, document and status surface.

> Public integration means that a strategy is documented, linked and bounded. It does not mean that the strategy is operational, certified, legally compliant, commercially validated or promoted.

## Four-layer interpretation

The public profile distinguishes four layers. **Identity** identifies the ecosystem. **Documentation** states contracts and boundaries. **Evidence** records reproducible checks, artifacts and reviews. **Operation** requires execution in a declared environment, evidence, replay/reproduction and human authorization. A strategy can be publicly documented without being operational.

## Non-transferable material

Secrets, credentials, private endpoints, sensitive telemetry, personal data not reviewed for publication, customer information, financial execution data and unverified legal or commercial claims remain outside this public register.

## Current global boundary

The current public projection is:

> `GREEN-STAGING-CANDIDATE · EVIDENCE-SCOPED · PROMOTION BLOCKED`

The profile is a governed entry point. The control plane remains the source of truth for claims, state projection, evidence classification and promotion decisions.
