# Valoración competitiva y posicionamiento evidence-scoped de CASTÚO-SYSTEM

**Fecha:** 19 de agosto de 2026  
**Estado:** `PUBLIC SURFACE · EVIDENCE-SCOPED`  
**Documento relacionado:** [análisis competitivo digital](CASTUO_SIMILARWEB_COMPETITIVE_ANALYSIS_2026-08-19.md)

## Conclusión defendible

El análisis competitivo muestra una superficie pública transversal para CASTÚO, pero no demuestra cuota de mercado, rendimiento comercial, superioridad tecnológica ni producción validada. La formulación estratégica más rigurosa es:

> **CASTÚO-SYSTEM provides evidence-ready continuity for disconnected field operations.**

En términos técnicos, CASTÚO se presenta como una dirección de infraestructura basada en evidencia para operaciones distribuidas resilientes, combinando workflows offline-first, continuidad Edge/IoT, assurance, recuperación y promoción gobernada. La formulación describe la propuesta y su frontera pública; no convierte capacidades experimentales o target en capacidades de producción.

La matriz visual revisada cubre seis dimensiones: **offline field**, **evidence/assurance**, **IoT/telemetry**, **dashboards**, **workflow/integrations** y **analytics**. La cobertura completa de CASTÚO significa que las dimensiones están descritas en la superficie pública revisada. No significa que estén todas integradas, validadas remotamente, disponibles en producción o respaldadas por clientes.

## Diferenciación defendible

CASTÚO no debe presentarse como “más completo que todos sus competidores”. La formulación controlada es:

> CASTÚO conecta continuidad offline-first, captura de evidencia, assurance, recuperación y gates de promoción en una arquitectura gobernada para operaciones distribuidas.

La hipótesis de diferenciación combina:

```text
Offline continuity
        +
Evidence fabric
        +
Assurance / recovery
        +
Fail-closed gates
        +
Human review
```

Esta combinación es una **hipótesis de posicionamiento**, no una ventaja competitiva demostrada. Para elevarla se necesitan pruebas comparables, usuarios, pilotos y resultados medidos.

## Qué aporta este análisis

El mapa competitivo delimita el universo relevante, identifica el espacio de posicionamiento, evita reducir CASTÚO a AgTech o IA y orienta la siguiente fase de validación comercial. También muestra que CASTÚO no tiene que presentarse como sustituto directo de cada plataforma. Puede plantearse como una capa de continuidad, evidencia y governance que complemente sistemas de campo, IoT, dashboards o automatización.

## Próximo experimento competitivo

Para convertir la hipótesis conceptual en una comparación operacional, debe ejecutarse un vertical slice con conectividad intermitente:

```text
Sistema convencional
→ pérdida de conectividad
→ trabajo manual o interrupción
→ recuperación y reconstrucción de datos

CASTÚO
→ pérdida de conectividad
→ operación local
→ buffering
→ sincronización
→ evidencia verificable
→ informe revisable
```

Los KPI mínimos son: tiempo de continuidad, datos perdidos, tiempo de recuperación, trabajo manual requerido, incidencias de sincronización, tiempo hasta generar el informe, confianza del usuario y coste evitado. Estos KPI son **requisitos de medición futura**, no resultados actuales.
